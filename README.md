# הרכב מוזיקלי תשפ״ז

ספר שירים לנגינה: אקורדים מעל המילים, העברת טונים, הצגת הערות וגלילה אוטומטית. מותאם לטלפון, וניתן להתקין אותו כאפליקציה.

## קבצים

- `index.html` – האפליקציה כולה (השירים נמצאים בראש הסקריפט, במערך `SONGS`)
- `manifest.webmanifest`, `sw.js`, `icons/` – התקנה כאפליקציה ועבודה בלי חיבור
- `tools/make-artifact.py` – יוצר מ־`index.html` את גרסת ה־Artifact של claude.ai

## הפעלה כאתר

ב־GitHub: Settings ← Pages ← Source: Deploy from a branch ← Branch: `main`, תיקייה `/ (root)`.
הכתובת תהיה `https://rb077858.github.io/herkev/`.

## התקנה בטלפון

ב־Chrome פותחים את הכתובת, ואז בהגדרות (הכפתור בראש העמוד) לוחצים על "התקנת האפליקציה".
אם הכפתור לא מופיע: תפריט Chrome ← "התקנת אפליקציה" או "הוספה למסך הבית". ב־iPhone: Safari ← שיתוף ← "הוספה למסך הבית".

## הוספת שיר

מוסיפים אובייקט ל־`SONGS` ב־`index.html`:

```js
{
  id: 'song-id', title: 'שם השיר', meter: '3/4', key: 'E',
  structure: ['פתיחה', 'פזמון 1', 'בית'],          // סדר הנגינה המלא, כולל חזרות
  sections: [
    { name: 'פתיחה', label: 'פתיחה · נגינה', lines: [ { c: ['E', 'A', 'D'] } ] },
    { name: 'פזמון 1', lines: [ { c: ['E', 'A'], l: 'מילים', n: 'הערה אופציונלית' } ] }
  ]
}
```

חלק שמופיע כמה פעמים ב־`structure` מוצג במלואו בכל פעם. שורת `{ note: 'טקסט' }` היא הערה עצמאית, וניתן להסתיר הערות בהגדרות.

### תיבות ושינויי קצב

במקום `c` (אקורד אחד לתיבה) אפשר לכתוב `m` ו־`ls`: רשימת תיבות ורשימת שורות מילים.
תיבה נכתבת `'Fmaj7'`, או `'F G'` (שני אקורדים באותה תיבה), או `'5/4 Fmaj7'` (הקצב משתנה מהתיבה הזאת והלאה, מוצג מעל התיבה).

```js
{ m: ['2/4 Am G', '4/4 Em F'], ls: ['לא בחיל ולא בכח'] }
```

- `structure` יכול להכיל `{ name: 'פזמון', x: 4 }`: החלק נכתב במלואו ארבע פעמים.
- `mode: 'minor'` בשיר קובע איות במבני במול בהעברת טונים (ברירת מחדל: מז'ורי).
- `mixed: true` מסמן בבחירת השיר שהקצב משתנה.
- איבר ב־`structure` יכול להיות גם `{ name, x, who, take, label, chip, note }`: `who` שמות המבצעים לכל חזרה, `take` רק N השורות הראשונות של החלק, `label` ו־`chip` משנים את הכותרת ואת כפתור הקיצור, `note` מוצג מתחת לכותרת.
- הערה על שורה: `n`, ואפשר להגביל אותה לחזרה מסוימת עם `nRep` (בחלק שחוזר `x` פעמים).

`meter` אופציונלי: שיר בלי קצב מוגדר לא מציג אותו.
`flatTonics` אופציונלי: רשימת צלילי טוניקה (0=C עד 11=B) שבהם האקורדים מאויתים בבמולים (Bb ולא A#), ובשאר בדיאזים. ברירת המחדל נקבעת לפי `mode`.

בסוף כל שיר יש כפתור "חזרה לתחילת השיר", ולחיצה על שם המפתח בראש השיר פותחת רשימת מפתחות לבחירה.
